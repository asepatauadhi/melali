## Build APK

**GitHub Actions:** upload proyek ini ke GitHub, buka tab Actions, jalankan "Build APK", lalu unduh APK dari Artifacts.

**Lokal:** buka di Android Studio, atau jalankan `gradle assembleDebug` (Gradle 8.9+, JDK 17).

Dibuat dengan Html/web2Apk.
